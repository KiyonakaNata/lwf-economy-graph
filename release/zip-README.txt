LWF Economy Graph
Lazy Witch's Factory の統計画面に、収支のグラフを描き足す MOD
Draws income / expense graphs into the game's stats screen

────────────────────────────────
入れかた
────────────────────────────────

1. BepInEx 5 を落として、ゲームのフォルダ
   （LazyWitchsFactory.exe と同じ場所）へ展開する

     https://github.com/BepInEx/BepInEx/releases
     BepInEx_win_x64_5.4.x.zip

2. 一度ゲームを起動して終了すると、BepInEx/plugins などが作られる

3. LwfEconomyGraph.dll を BepInEx/plugins/ に入れる

4. ゲームを起動し、統計画面を開く

────────────────────────────────
消しかた
────────────────────────────────

BepInEx/plugins/LwfEconomyGraph.dll を消す

────────────────────────────────
使いかた・設定・不具合の報告
────────────────────────────────

     https://github.com/KiyonakaNata/lwf-economy-graph

Lazy Witch's Factory ver 0.24.1 / BepInEx 5.4.23.5 で確認
非公式のMOD、公式のサポート対象外


================================================================

────────────────────────────────
Install
────────────────────────────────

1. Download BepInEx 5 and extract it into the game folder
   (the folder that contains LazyWitchsFactory.exe)

     https://github.com/BepInEx/BepInEx/releases
     BepInEx_win_x64_5.4.x.zip

2. Run the game once and quit, so that BepInEx/plugins is created

3. Put LwfEconomyGraph.dll into BepInEx/plugins/

4. Start the game and open the stats screen

────────────────────────────────
Uninstall
────────────────────────────────

Delete BepInEx/plugins/LwfEconomyGraph.dll
