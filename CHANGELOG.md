# Changelog

## 1.0.4 — 2026-11-04

- Trophy, Utter Satisfaction, Mineral Seedling, Vault Seedling and other newer income sources use their icon colours
- Taxation is no longer counted as Land Purchases
- The Repayment entry under Expenses uses Gehenna's smiling face
- Land Swindler income uses Mammon's icon
- Repaying through a portal no longer counts the payment twice
